# CGNS Libraries Extension (omni.cae.cgns_libs)

This legacy compatibility extension provides CGNS library support for
`omni.cae.delegate.cgns`. Active file-format support uses `omni.cae.usd_plugins`.

## Dependencies

This extension:

- Depends on `omni.cae.hdf5_libs` (CGNS requires HDF5)
- Provides CGNS libraries for version 4.5.0
